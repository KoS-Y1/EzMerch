# EzMerch

[English](../README.md)

EzMerch 是一款用于处理美工素材的桌面工具。你可以导入 PNG 图片、裁剪透明边缘、添加刀线和白色出血线，并导出单张图片或半切贴纸整版。

## 下载

- [下载 v0.1.0](https://github.com/KoS-Y1/EzMerch/releases/tag/v0.1.0)

## 功能

- 自动裁剪素材周围的透明边缘。
- 添加刀线，并调整刀线的距离和粗细。
- 添加白色出血线，并调整其距离。
- 保持比例并调整单张贴纸的尺寸。
- 自动排版半切贴纸画布，并调整边距和贴纸间间距。
- 支持像素和毫米单位，以及可配置的输出分辨率。
- 导出合并图层的 PNG 图片或保留图层的 RGB PSD 文件。

## 快速开始

### 运行 Windows 可执行文件

从上方的发布页面下载 `EzMerch.exe`，将其放在有写入权限的文件夹中，双击即可启动。运行打包后的程序无需安装 Python。

### 在 Windows 上从源码运行

安装 Python 3.13，然后下载或克隆本仓库。在项目文件夹中打开 PowerShell，运行：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 使用 EzMerch

### 加载素材

1. 点击**选择图片**，选择一张或多张 PNG 图片。建议使用透明背景的素材。
2. 点击**加载**，准备处理所选图片。EzMerch 会自动裁剪图片外围的透明边缘。
3. 查看加载结果，确认是否有加载失败的文件。

添加、移除或清除图片后，请在导出前重新点击**加载**。

### 导出单件美工

1. 选择**单件美工**选项卡。
2. 如需调整素材尺寸，勾选**启用尺寸调整**，然后在**输出设置**中设置宽度、高度、单位和分辨率。图片会保持比例，缩放至指定画布内，并为已启用的边框预留空间。
3. 按需勾选**启用刀线**，调整刀线的距离、厚度和单位。
4. 按需勾选**启用出血线**，调整距离和单位。这会在素材周围添加白色出血线。
5. 选择 `png` 或 `psd` 格式，指定**导出文件夹**，然后点击**导出**。
6. 查看导出结果。每张已加载的图片都会生成一个独立的输出文件。

未启用尺寸调整时，素材会保留裁剪后的像素尺寸，并为已启用的边框增加空间。输出分辨率默认为 300 dpi。

### 导出半切贴纸整版

1. 加载图片后，选择**半切贴纸**选项卡。
2. 在**输出设置**中设置整版的宽度、高度、单位和分辨率。
3. 设置**画布边距**，控制画布边缘向内预留的空间；设置**贴纸间距**，控制相邻贴纸之间的间隔。
4. 在贴纸设置中按需启用刀线和白色出血线。
5. 选择 `png` 或 `psd` 格式，指定**导出文件**，然后点击**导出**。
6. 查看整版贴纸的导出结果。

EzMerch 会自动将贴纸排列成网格，并保持每张贴纸的宽高比，将其缩放至对应单元格内。

毫米尺寸会根据输出 DPI 转换为像素。请根据预期的打印尺寸选择合适的画布尺寸和分辨率。
